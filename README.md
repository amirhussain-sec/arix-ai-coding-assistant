## 🚀 About ARIX AI

**ARIX AI** is an intelligent personal AI coding assistant that helps developers write, understand, debug, and optimize code through an interactive AI-powered experience.

ARIX AI combines intelligent coding capabilities, natural voice interaction, and a modern user interface to create a more engaging programming experience.

Whether you are a beginner learning programming or an experienced developer building applications, ARIX AI aims to be your personal coding companion.

- 🤖 **AI Code Generation** – Generate code from natural-language instructions.

## ⚙️ Installation & Setup

Follow these steps to run ARIX AI locally.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/arix-ai-coding-assistant.git
```

**2. Navigate to the project**

```bash
cd arix-ai-coding-assistant
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file and add your required API credentials.

```env
AI_API_KEY=your_api_key_here
```

Never upload your actual API keys to GitHub.

**5. Start the application**

```bash
npm run dev
```

Use the appropriate start command from your project's package.json if it differs.
